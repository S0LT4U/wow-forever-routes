# WoW Forever Dungeon Routes

Static site with boss locations and suggested routes for WoW Forever dungeons (levels 13-60).

- `index.html` - the whole site (no build step)
- `dungeons.json` - dungeon list, level ranges, boss order and notes
- `img/` - full route maps (`.webp` for the site, `.png` for Discord) and thumbnails

## Hosting on GitHub Pages
Settings -> Pages -> Source: "Deploy from a branch" -> Branch: `main`, folder `/ (root)`.

Boss positions from MetaForge spawn data; map art (c) Blizzard Entertainment. Fan-made, unaffiliated.
